Face feature detection

Detects facial features (ear, eyes, nose, lips) using a custom YOLO model that runs in your browser.

Before you start

Video is processed in this browser only. Nothing is uploaded and no images are saved. The log keeps only times and counts.

  • Secure page (localhost or https)
  • Runtime library loaded
  • Model loaded (best.onnx, classes.json)
  • Camera started
